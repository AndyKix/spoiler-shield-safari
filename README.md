# Spoiler Shield для Safari

Расширение для YouTube: скрывает видео по словам в заголовке и убирает комментарии. Работает локально, без ИИ, аккаунта расширения, серверов и аналитики.

**[Скачать приложение для Mac — версия 1.3.0](https://github.com/AndyKix/spoiler-shield-safari/raw/refs/heads/main/downloads/Spoiler-Shield-1.3.0-macOS.zip)** · [Исходники расширения](extension) · [Контрольная сумма](downloads/SHA256SUMS)

## Что умеет

- Скрывает карточку целиком: заголовок, обложку и ссылку. Проверяет главную страницу, поиск, рекомендации и поддерживаемые карточки Shorts.
- Учитывает новые карточки при прокрутке и изменении страницы.
- Скрывает комментарии под видео и панели комментариев Shorts. Можно отключить отдельно от фильтра видео.
- Позволяет редактировать список слов. В стандартном списке уже есть варианты GTA 6, GTA VI, GTA6 и ГТА6.
- Поддерживает светлую и тёмную темы системы.

Совпадение — подстрока без учёта регистра. Одна строка списка — одно слово или фраза. Пустой список не скрывает ролики по заголовку.

## Установка готовой сборки на Mac

Сборка содержит оба варианта процессора: Apple Silicon и Intel. Целевая версия macOS — 12 или новее; Safari должен поддерживать WebExtension Manifest V3. Работа проверялась на одном Mac, поэтому совместимость со всеми версиями системы не гарантируется. iPhone и iPad эта сборка не поддерживает.

Это сборка для локальной разработки с подписью ad hoc, без Apple Developer ID и нотариализации. Для её использования Safari потребуется разрешить неподписанные расширения.

1. Скачайте ZIP по ссылке выше и распакуйте.
2. Переместите **Spoiler Shield.app** в папку **Программы** и откройте приложение хотя бы один раз. Не удаляйте его после установки: внутри находится расширение.
3. Если macOS блокирует запуск из-за неизвестного разработчика, воспользуйтесь штатным разрешением для этого конкретного приложения в **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. Делайте это только если доверяете этой сборке; подробности — в [инструкции Apple](https://support.apple.com/102445).
4. В **Safari → Настройки → Дополнения** включите **«Показывать функции для веб-разработчиков»**. В старых версиях название может отличаться.
5. В разделе **Разработчик** включите **«Разрешить неподписанные расширения»**. В некоторых версиях Safari эта команда находится в меню **Разработка**. Системный пароль вводится в окне macOS.
6. Откройте **Safari → Настройки → Расширения** и включите **Spoiler Shield**. В приложении есть кнопка перехода к этим настройкам.
7. Откройте YouTube, нажмите кнопку Spoiler Shield в панели Safari и выберите **«Разрешать всегда на этом сайте»**. Разрешать доступ ко всем сайтам не требуется.
8. Обновите уже открытые вкладки YouTube: **⌘R**.

Если Safari сообщает об обнаружении автоматизированных нажатий, включите галочку вручную после завершения программы автоматизации. Если после перезапуска Safari локальное расширение перестало работать, проверьте разрешение неподписанных расширений и галочку Spoiler Shield. Это ограничение сборки для разработки.

[Официальная инструкция Apple по включению и диагностике расширений](https://developer.apple.com/documentation/safariservices/troubleshooting-your-safari-web-extension).

## Настройка

Нажмите кнопку Spoiler Shield в Safari:

- **Фильтр видео** включает скрытие по заголовкам.
- **Скрывать комментарии** убирает поддерживаемые блоки комментариев; по умолчанию включён.
- Введите слова или фразы по одной на строку и нажмите **«Сохранить изменения»**. Новые настройки применяются к открытым страницам.
- **«Вернуть список GTA 6»** заполняет стандартные слова. Для применения также нажмите «Сохранить изменения».

## Собрать из исходников без полного Xcode

Нужны macOS, Python 3 и Apple Command Line Tools. Если инструментов Apple ещё нет, установите их командой `xcode-select --install` и завершите установку в системном окне.

```sh
git clone https://github.com/AndyKix/spoiler-shield-safari.git
cd spoiler-shield-safari
python3 native/build.py
```

Приложение появится в **dist/Spoiler Shield.app**. Скрипт собирает универсальные бинарные файлы, копирует ресурсы WebExtension и подписывает приложение локальной подписью ad hoc. Далее следуйте инструкции установки выше.

В новых версиях Safari можно также временно подключить папку **extension/** через **Разработчик → Добавить временное расширение**, если такая команда доступна. Это режим разработки, а не постоянная установка. Подробнее — в [документации Apple](https://developer.apple.com/documentation/safariservices/safari-web-extensions).

## Ограничения и приватность

Фильтр заголовков не распознаёт спойлеры на картинках, в речи и в роликах без ключевых слов. Он не закрывает уже открытое видео и не запрещает переход по прямой ссылке. Комментарии скрываются целиком, без анализа содержания; чат трансляций не скрывается. Изменения разметки YouTube могут потребовать обновления расширения.

Доступ ограничен `youtube.com`, `www.youtube.com` и `m.youtube.com`. Заголовки и комментарии никуда не отправляются. Список слов хранится в локальном хранилище расширения. Учётные данные, пароли, токены, переписка и история браузера в репозиторий не включены.

## Структура и проверки

```text
extension/     JavaScript, HTML, CSS и manifest.json
native/        macOS-приложение, обработчик расширения и скрипт сборки
downloads/     Готовое приложение в ZIP и SHA-256
tests/         Локальные страницы для проверки поведения
```

Выполнены проверки синтаксиса, миграции настроек, 21 сценарий DOM и сценарии меню с ошибками хранилища. Эти проверки воспроизводят варианты разметки и API хранилища; они не гарантируют совместимость со всеми изменениями живого YouTube. Инструкция запуска — в [tests/README.md](tests/README.md).

Чтобы удалить расширение, выключите его в настройках Safari и удалите приложение Spoiler Shield из папки «Программы».
