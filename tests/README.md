# Проверки на локальных страницах

Фикстуры используют настоящий DOM браузера и тестовую реализацию browser.storage. Файлы расширения подключаются напрямую из extension/, без изменения исходников.

```sh
python3 tests/run.py
```

Нужен Google Chrome. При нестандартном расположении:

```sh
python3 tests/run.py --chrome /путь/к/chrome
```

Запускается отдельный временный профиль без доступа к вашему обычному профилю. Проверяются фильтрация карточек, комментарии, настройки, ошибки хранения и гонка при первоначальном чтении. Настройки и сайт реального аккаунта не используются. Проверки не заменяют тестирование упакованного расширения в Safari.
